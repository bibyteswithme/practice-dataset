**Practice Datasets**

A growing collection of beginner-friendly datasets for practicing data analysis. Each entry notes what it's good for and links to the source or folder.

2. Mock Marketing Dashboard

3. Telco Customer Churn

Real-world telecom dataset used in my churn EDA project , good for practicing churn analysis, segmentation, and distributions. 🔗 Kaggle source
